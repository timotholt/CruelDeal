CYBERPUNK CCG — DESIGN DOCS README v0.1
Created: 2026-04-23

Files in this bundle:

1. Cyberpunk_CCG_Domain_Bible_v0.1.txt

   The foundation spec.
   Defines design philosophy, player-facing rules vocabulary, domains, tags,
   launch archetypes, and deferred mechanics.

2. Cyberpunk_CCG_Tracked_Variables_Matrix_v0.1.txt

   The engine/design matrix.
   Lists the tracked game facts that cards may care about, including visibility,
   safety, launch use, archetypes, and example mechanical use.

3. Cyberpunk_CCG_Launch_Archetype_Packages_v0.1.txt

   The pre-card-design package spec.
   Defines launch archetype slots, bridge maps, secondary packages, and suggested
   100+ card allocation.

Important design call:

   Do not make lore words into rules keywords.

Use simple rules text:
   On Reveal
   Ongoing
   Activate
   When Destroyed
   End of Turn
   Draw
   Add
   Copy
   Destroy
   Move
   Reduce Cost

Use cyberpunk flavor in:
   card names
   tags
   art
   deck names
   archetype identity

Next design step after these files:

   Build the first 100-card slot map, not the actual card list yet.

Example:
   Destroy / Enabler / 2-Cost / destroys friendly card
   Fixer / Enabler / 3-Cost / draws Tech card
   Nanotech / Payoff / Ongoing / buffs cards here
   Black Market / Bridge / created card / self-destructs

After the slot map is stable, begin actual card names and text.
